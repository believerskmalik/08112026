# 🎁 QUICK START — 3 Steps to Magic

## Step 1: Add Photos (2 minutes)
```
Create this folder in your project:
  images/

Add your photos to it:
  images/01.jpg
  images/02.jpg
  images/03.jpg
  ... (name them 01, 02, 03, etc.)

Supported: .jpg, .png, .webp, .jpeg
Recommended: Square images, 300-800px
```

## Step 2: Open Page (1 click)
```
Double-click:  index.html

OR right-click → Open with → Your Browser
```

## Step 3: Experience Unfolds ✨
```
🎵 Audio plays automatically
🌹 Roses fall from top (cinematic background)
🌳 Animated tree grows with messages
🎁 Click "Open Gift" button
📸 See her photo gallery
💕 Read closing special message
```
