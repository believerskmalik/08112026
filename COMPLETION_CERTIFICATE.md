## 🚀 To Use It (3 Simple Steps)

### STEP 1: Create Images Folder
```
In your project root, create a folder named:
  images/

Then add your photos to it:
  images/01.jpg
  images/02.jpg
  images/03.jpg
  images/04.jpg
  ... (up to 20 photos)
```

**Supported formats:** `.jpg`, `.png`, `.webp`, `.jpeg`  
**Recommended:** Square images, 300-800px  
**Naming:** `01.jpg`, `02.jpg`, etc. (with leading zeros)

### STEP 2: Open in Browser
```
Double-click: index.html

OR

Right-click → Open with → Your Browser
```

In `index.html` around line 270, uncomment:
```javascript

//     window.openClosingModal();
```

This will auto-show the closing message when gallery closes.
