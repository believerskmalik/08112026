## Interactions & Hover States

### Gift Button Hover
```
Normal:
  Background: Gradient rose→gold
  Border: 2px gold
  Glow: Medium intensity
  
Hover:
  Background: Same (smooth)
  Border: Brighter gold
  Glow: INTENSE gold glow (increased opacity)
  Transform: translateY(-2px) — lifts slightly
  Shadow: Larger, more pronounced
```

### Gallery Image Hover
```
Normal:
  Border: 1px gold (subtle)
  Scale: 1.0
  Brightness: 1.0
  
Hover:
  Border: 2px gold (more visible)
  Scale: 1.05 (zoom in)
  Brightness: 1.1 (10% brighter)
  Shadow: Gold glow intensifies
```

### Button Focus (Keyboard)
```
Focused:
  Outline: 3px solid gold
  Outline-offset: 2px
  (Visible to keyboard users)
```
